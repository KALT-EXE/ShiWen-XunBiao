# v1.1.0 — 整行输出、窗口置顶、自定义快捷键

这是一个面向日常查表场景的更新，重点解决三个问题：结果不够完整、窗口容易被遮挡、全局快捷键冲突。

## 新增

- **完整整行输出**
  - 结果下方新增「整行内容」面板，展示该行全部非空字段。
  - 自动选中第一条结果，立即显示完整内容。
  - 一键复制整行，不再有省略号或字段截断。
- **窗口始终置顶**
  - 默认显示在其他窗口上方。
  - 右上角「置顶：开 / 关」可随时切换，状态自动记住。
- **自定义全局快捷键**
  - 默认改为 `Ctrl + Shift + Q`。
  - 点击左侧「更改」可现场录制新组合键。
  - 内置 `Ctrl + Shift + Q`、`Alt + Shift + Q`、`Ctrl + Alt + S` 三组推荐组合。
- **快捷键冲突提示**
  - 新组合被占用时保留原快捷键，并提示冲突。
  - 绿色「框选屏幕文字」按钮始终可用。

## 改进

- 结果列表默认自动选中第一条并展开整行详情。
- 小窗口自动收起详情面板，优先保证结果列表可操作。
- 完善帮助说明、高 DPI 布局和快捷键设置界面。
- 新增核心单元测试、GitHub Actions、Issue / PR 模板。

## 安装

1. 下载 `识文寻表-v1.1.0.zip`。
2. 解压后双击 `识文寻表.exe`。
3. 首次启动会自动载入示例数据。

## 环境要求

- Windows 10 / 11
- Python 3.10+（运行源码或 exe 启动器时需要）
- Pillow
- Windows 中文（简体）OCR 语言组件
- Microsoft Excel（可选，用于双击定位单元格）

> `识文寻表.exe` 是轻量启动器，不是包含 Python 运行时的独立安装包。请保持解压目录完整。

## 已知限制

- 仅支持 Windows。
- 不支持 `.xls` / `.xlsb`，请先另存为 `.xlsx`。
- Excel 公式需要已保存缓存值；隐藏工作表不会被检索。
- OCR 准确率取决于框选清晰度、字体与对比度；建议给文字留边距。
